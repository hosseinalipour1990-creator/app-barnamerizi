# برنامه‌ریز

یک نمونهٔ اولیهٔ بومی اندروید برای مدیریت کارها، برنامهٔ روزانه، عادت‌ها و هدف‌ها. رابط کاربری با Jetpack Compose، به‌صورت راست‌به‌چپ و با تم حرفه‌ای تیره ساخته شده است.

## قابلیت‌های فعلی

- داشبورد روزانه با پیشرفت کارها و برنامهٔ زمانی
- تقویم هفتگی و نمایش تاریخ فارسی
- فیلتر و تکمیل کارها، به‌همراه افزودن کار جدید
- پیگیری هفتگی عادت‌ها و زنجیرهٔ استمرار
- نمایش هدف‌ها، مهلت و درصد پیشرفت
- رابط واکنش‌گرا با Material 3 و پشتیبانی کامل RTL

داده‌های این نسخه نمونه و در حافظه هستند و پس از بسته‌شدن برنامه بازنشانی می‌شوند. ذخیره‌سازی محلی و اعلان‌ها در مرحلهٔ بعدی اضافه خواهند شد.

## فناوری‌ها

- Kotlin 2.0.21
- Jetpack Compose + Material 3
- Android Gradle Plugin 8.7.3
- حداقل Android 8 (API 26)، هدف Android 15 (API 35)

## ساخت و آزمون

پیش‌نیازها: JDK 17 و Android SDK Platform 35.

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

خروجی APK دیباگ در مسیر زیر ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```
